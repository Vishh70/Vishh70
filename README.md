<details>
<summary><b>🏛️ GrievanceIQ — Civic Intelligence Platform</b></summary>
<br/>
<b>AI-powered civic grievance processing and dependency-aware workflow system.</b>

- **Problem:** Civic complaints are unstructured, duplicated, and difficult to route across municipal departments.
- **Solution:** A pipeline that separates probabilistic ML classification from deterministic execution workflows.
- **Engineering Depth:** 
  - Uses `MiniLM-L6-v2` embeddings and a multi-label Logistic Regression classifier (98.53% Micro-F1) for semantic understanding.
  - Implements a Random Forest relationship detector to aggregate duplicate complaints into isolated Civic Issues using Connected Components graph traversal.
  - Generates Directed Acyclic Graphs (DAGs) for deterministic task routing via Kahn's algorithm and transactional PostgreSQL execution.
- **Tech Stack:** `React`, `Node.js`, `Python`, `Flask`, `Supabase (PostgreSQL)`, `BullMQ`, `Redis`, `Scikit-learn`
- **[View Repository](https://github.com/Vishh70/grievanceiq)**

<summary><b>🏭 TE Connectivity Predictive Monitoring — ML Pipeline</b></summary>
<br/>
<b>Machine-learning system converting rolling manufacturing telemetry into operator-facing scrap-risk predictions.</b>

- **Problem:** High-volume mechanical scrap due to unforeseen mechanical tolerance drifts.
- **Solution:** An end-to-end machine learning inference server with a real-time operator dashboard.
- **Engineering Depth:**

- **Tech Stack:** `Python`, `FastAPI`, `LightGBM`, `Pandas`, `React`, `Vite`

<details>
<summary><b>🛡️ Self-Learning AI IDS — Cybersecurity Infrastructure</b></summary>
<br/>
<b>Unsupervised network anomaly detection using low-latency packet feature extraction.</b>

- **Problem:** Signature-based network monitoring fails against novel (zero-day) threat patterns.
- **Solution:** A prototype network intrusion detection system utilizing continuous packet sniffing and statistical outlier mapping.
- **Engineering Depth:**
  - Designed a real-time Scapy-based pipeline to extract 16 distinct feature vectors (transmission metrics, protocol indicators) from raw PCAP traffic.
  - Utilizes an unsupervised `Isolation Forest` model, dynamically calibrating raw decision functions into a human-readable 1-100% risk index.
  - Validated by an automated, highly-structured 25-suite `Pytest` testing architecture.
- **Tech Stack:** `Python`, `Scapy`, `Scikit-learn`, `Flask`, `Pytest`
- **[View Repository](https://github.com/Vishh70/Self-Learning-AI-Intrusion-Detection-System-IDS-)**
