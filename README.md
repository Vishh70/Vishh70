### 🏭 [TE Connectivity Predictive Monitoring](https://github.com/Vishh70/te-connectivity-predictive-maintenance) | *Machine-Learning Pipeline*

- **Engineering Highlights**: Features a production LightGBM inference model processing wide feature vectors via a FastAPI backend, developed after evaluating experimental Random Forest baselines.
- **Tech Stack**: `Python` `FastAPI` `LightGBM` `Pandas` `React` `Vite`

- **Engineering Highlights**: Analyzes PCAP traffic using Scapy to construct 16-feature vectors, relying on an Isolation Forest model and dynamic risk calibration rather than static signatures. Validated via automated Pytest suites.
- **Tech Stack**: `Python` `Scapy` `Scikit-learn` `Flask` `Pytest`
