## 🚀 Featured Engineering Projects

### 🏛️ [GrievanceIQ](https://github.com/Vishh70/grievanceiq) | *Civic Intelligence Platform*
> AI-powered civic grievance processing and dependency-aware workflow system.
- **Engineering Highlights**: Separates probabilistic machine learning (MiniLM classification, Random Forest relationship detection) from deterministic execution (DAGs, Kahn's algorithm, transactional PostgreSQL routing). Operations are managed via near-real-time async polling.
- **Tech Stack**: `React` `Node.js` `Python` `Flask` `Supabase` `BullMQ` `Redis` `Scikit-learn`

### 🏭 [TE Connectivity Predictive Monitoring](https://github.com/Vishh70/te-connectivity-predictive-maintenance) | *Machine-Learning Pipeline*
> ML predictive monitoring system converting rolling manufacturing telemetry into operator-facing scrap-risk predictions.
- **Engineering Highlights**: Features a production LightGBM inference model processing wide feature vectors via a FastAPI backend, developed after evaluating experimental Random Forest baselines.
- **Tech Stack**: `Python` `FastAPI` `LightGBM` `Pandas` `React` `Vite`

### 🛡️ [Self-Learning AI IDS](https://github.com/Vishh70/Self-Learning-AI-Intrusion-Detection-System-IDS-) | *Cybersecurity Infrastructure*
> Unsupervised network anomaly detection using low-latency packet feature extraction.
- **Engineering Highlights**: Analyzes PCAP traffic using Scapy to construct 16-feature vectors, relying on an Isolation Forest model and dynamic risk calibration rather than static signatures. Validated via automated Pytest suites.
- **Tech Stack**: `Python` `Scapy` `Scikit-learn` `Flask` `Pytest`

### 🍽️ [Smartnivad](https://github.com/Vishh70/Smartnivad) | *Full-Stack Platform*
> Production-oriented web platform built with Next.js, integrating content assistance and strict QA pipelines.
- **Engineering Highlights**: Built on a server-rendered Next.js architecture with Prisma relational data modeling, enforced by strict Playwright E2E testing and Lighthouse CI performance budgets.
- **Tech Stack**: `Next.js 15` `Prisma` `PostgreSQL` `NextAuth` `Playwright` `TailwindCSS`

### 📦 [ARTI Enterprises](https://github.com/Vishh70/box-manufacturers-website) | *Client-Facing Engineering*
> Production client-facing website built with 3D product visualization and SEO engineering.
- **Engineering Highlights**: Implements interactive 3D WebGL configurators utilizing Three.js and Vite, deployed with strict accessibility auditing.
- **Tech Stack**: `Vite` `Three.js` `JavaScript` `HTML/CSS`
